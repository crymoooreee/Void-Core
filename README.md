# VoidCore

**VoidCore** — инструмент для мониторинга производительности игр, который отслеживает FPS, фиксирует просадки производительности и помогает определить, **из-за чего именно произошёл фриз или падение FPS**.

Проект ориентирован на игроков и разработчиков, которым важно не просто увидеть низкий FPS, а понять причину проблемы.

## 🎮 Основная идея

Обычные FPS-счётчики показывают только результат:

> FPS упал со 120 до 45.

VoidCore пытается ответить на следующий вопрос:

> **Почему FPS упал?**

Во время игры приложение собирает информацию о состоянии системы и сопоставляет её с моментами падения FPS.

Например:

```text
FPS DROP DETECTED

120 FPS → 48 FPS

Причина:
GPU Load:       98%
GPU Temperature: 82°C
CPU Load:       54%
RAM Usage:      71%
VRAM Usage:     96%

Вероятная причина:
Высокая загрузка VRAM
```

## 🔍 Что отслеживает VoidCore

В зависимости от доступных данных VoidCore может анализировать:

* FPS
* Frame Time
* GPU Load
* GPU Temperature
* GPU Power
* VRAM Usage
* CPU Load
* CPU Temperature
* RAM Usage
* процесс активной игры
* фоновые процессы
* резкие изменения нагрузки
* длительность фриза
* частоту и продолжительность просадок

## 📉 Обнаружение просадок FPS

VoidCore постоянно анализирует игровой FPS.

Когда производительность опускается ниже определённого порога или происходит резкий скачок Frame Time, создаётся событие:

```text
FPS DROP
──────────────

Time:       21:43:17
FPS:        144 → 62
Frame Time: 6.9ms → 16.1ms
Duration:   1.4s
```

Каждое такое событие может сохраняться для последующего анализа.

## 🧠 Определение причины

Главная задача VoidCore — связать падение FPS с состоянием системы в этот момент.

Например:

### GPU bottleneck

```text
GPU: 99%
CPU: 52%
VRAM: 68%

Result:
GPU-bound
```

### VRAM bottleneck

```text
GPU: 97%
VRAM: 99%

Result:
Possible VRAM limitation
```

### CPU bottleneck

```text
GPU: 61%
CPU: 96%

Result:
Possible CPU bottleneck
```

### Thermal throttling

```text
GPU Temperature: 87°C
GPU Clock: ↓
FPS: 140 → 73

Result:
Possible thermal throttling
```

### Background process

```text
FPS: 144 → 58

Background process:
Windows Defender
CPU usage: +31%

Result:
Possible background process interference
```

Результат является **анализом и вероятной причиной**, а не гарантированным диагнозом.

## 📊 История производительности

VoidCore может сохранять информацию о произошедших просадках:

```text
Game: Cyberpunk 2077

Session:
01:42:31

Average FPS:
118

1% Low:
72

0.1% Low:
48

FPS Drops:
17

Major Drops:
4
```

Для каждой значительной просадки можно посмотреть состояние системы в момент события.

## 🎯 Активная игра

VoidCore автоматически определяет запущенную игру и связывает собранную статистику с конкретной игровой сессией.

Пример:

```text
ACTIVE GAME

Counter-Strike 2

FPS       287
FrameTime 3.4 ms

GPU       72%
CPU       48%
RAM       61%
VRAM      54%
```

После закрытия игры сессия может быть завершена и сохранена в истории.

## ⚙️ Принцип работы

Упрощённо система работает следующим образом:

```text
Запуск игры
     │
     ▼
Определение активной игры
     │
     ▼
Начало игровой сессии
     │
     ▼
Сбор данных
     │
     ├── FPS
     ├── Frame Time
     ├── CPU
     ├── GPU
     ├── RAM
     └── VRAM
     │
     ▼
Обнаружена просадка?
     │
    Да
     │
     ▼
Анализ состояния системы
     │
     ▼
Определение вероятной причины
     │
     ▼
Сохранение события
```
